# MarketWatch

A self-contained, single-page market dashboard (the locked "V2.7" design) that
rebuilds itself from data each day and publishes to GitHub Pages.

**Live page:** https://infinite2142.github.io/MarketWatch/

## What's in the repo

| File | Role |
|---|---|
| `index.html` | The published page. Regenerated by `generator.py`; served at the site root. |
| `template_v27.html` | The locked V2.7 visual design (CSS + SVG + client-side render engine). Not edited by the pipeline. |
| `market_watch_data.json` | The data model — one key per page section. The single source of truth for content. |
| `generator.py` | Reads the template + JSON and writes a complete `index.html`. Stamps the build date each run. |
| `fetch_data.py` | Pulls the cleanly-sourceable numeric metrics (FRED CSV + Stooq/Yahoo) and writes them into the JSON. |
| `.github/workflows/deploy.yml` | The daily/dispatch/push automation. |

## How the pipeline works

The repo is the source of truth. Two sides keep it current:

**GitHub Actions** (this repo) runs daily at 06:30 UTC, on manual dispatch, and on
every push to `main`. It fetches the latest numeric market data, rebuilds the page,
commits any changed `index.html` + `market_watch_data.json` back to `main`, then
deploys to GitHub Pages. Actions runners have open outbound network, so the FRED
and Stooq/Yahoo feeds resolve there (they are blocked in the authoring sandbox).
The workflow authenticates with the built-in `GITHUB_TOKEN` — no personal access
token is involved in the recurring cycle.

**The authoring side (Cowork)** updates the analytical and ledger fields that have
no clean feed — the narrative, sector ratings, driver and theme cards, the signal
log, crash-risk read, and any metric flagged `estimate`. Those edits land in
`market_watch_data.json`; the next Actions run rebuilds and republishes from them.

So numeric metrics refresh automatically; judgement-based content is edited by hand.
Both meet in the same JSON.

## Data sources

`fetch_data.py` updates only fields it has a free, keyless feed for: FRED CSV
(`DGS10`, `VIXCLS`, `BAMLH0A0HYM2`, `BAMLC0A0CM`, `T10Y2Y`, `NFCI`, `SAHMREALTIME`,
`ICSA`, `DEXUSEU`, `BAMLEMHBHYCRPIOAS`) and Stooq/Yahoo price series (S&P, Nasdaq,
Dow, gold, Bitcoin, DXY, Brent, FTSE 100, Nikkei 225, MSCI EM via EEM, plus every
equity ticker in the data file). If a feed fails, the prior value is kept and the
field is marked stale rather than crashing the run. Editorial estimates and
narrative fields are left untouched.

## Secrets

None live in the repo. The pipeline uses only free, keyless public feeds and the
GitHub-provided `GITHUB_TOKEN`. Token/secret patterns are excluded via `.gitignore`.
